Description of Related Tools

#### dG Predictor (Thermodynamics)
**Function:** Calculates $\Delta_r G'^\circ$
- **Input:** Reaction Equation in KEDD IDs (A + B <=> C), pH=7.0 in default
- **Method:** Standard Gibbs energy change
- **Reference:** [Wang L, Upadhyay V, Maranas CD (2021) dGPredictor](https://doi.org/10.1371/journal.pcbi.1009448)

#### EnzRank (Affinity Prediction)
**Function:** Predicts the compatibility score between an enzyme sequence and a substrate.
- **Input:** Protein Sequence (FASTA) + Substrate ID (KEGG IDs)
- **Output:** Score (0-1)
- **Reference:** [Upadhyay V, Maranas CD (2023)](https://doi.org/10.1016/j.ymben.2023.06.001)
