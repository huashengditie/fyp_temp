Project Goal: To develop and evaluate an explainable AI agent (open-source LLMs) for pathway and strain engineering using GSM-derived structured data. 

Areas to cover:
-Strain-selection advisor: e.g., given a target chemical, rank microbes using stored yield data + explainable biological reasoning.
-Pathway engineering recommender
-Intervention-prioritization tool
-Cofactor-engineering explorer
-GSM simulation validation module

-Build a benchmark set of 50-100 GSM questions: (exact data lookup, host ranking, knockout/overexpression suggestion, cofactor engineering, explain with evidence, etc.)

-Evaluation Metrics: retrieval/numeric accuracy, hallucination rate, ranking consistency, explanation quality, simulation agreement, agent reliability, latency, cost and deployment (can smaller open models run locally and cheaply)

-Compare LLM models: Open-source models from Ollama library: Qwen, Kimi, smaller local baseline, (AI-know hosted LLM--> later).
